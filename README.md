## Short description
MovieVerse is a multi-page responsive movie website. It provides movie information, audience ratings, trailer previews and community reviews. The project demonstrates the HTML, CSS and Bootstrap topics covered in the course.

## Pages
1. Home — `index.html`
2. Movies — `movies.html`
3. Ratings — `ratings.html`
4. Trailers — `trailers.html`
5. Reviews — `reviews.html`

## Features implemented
- 5 connected pages
- Navigation bar visible on all pages
- Semantic HTML5: header, nav, main, section, article and footer
- Movie information cards
- Ratings comparison table
- Trailer preview cards
- Community reviews
- Review submission form
- CSS Flexbox
- CSS Grid
- Relative and absolute positioning
- Hover and focus states
- `:nth-child()` pseudo-class
- CSS variables in `:root`
- Google Font: Inter
- Bootstrap 5 navbar, containers, responsive grid, buttons, spacing and form utilities
- Media queries for tablet and mobile
- Consistent movie-themed visual design
- GitHub Pages ready
